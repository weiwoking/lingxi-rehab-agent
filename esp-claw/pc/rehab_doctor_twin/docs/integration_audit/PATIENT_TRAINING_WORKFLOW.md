# 患者人工训练流程

1. 患者打开 `/patient`，页面在没有设备数据时仍可使用，并显示“等待真实数据”。
2. 后端持续接收 UDP 6006，8 路图表只显示真实有效行。
3. 数据为 `RECEIVING` 且医生端存在唯一 active 正式任务时，“开始训练”可用。
4. 患者点击开始，后端冻结任务配置并创建唯一 session。
5. 训练中只缓存点击区间内后续收到的真实有效行。
6. 暂时断流时曲线冻结，不补零，不自动结束；“结束训练”仍可用。
7. 患者点击结束，缓存停止，实时接收继续。
8. 输入不足时标记 `INVALID`，不评分、不生成报告。
9. 有效输入保存 86 列 CSV，并通过评分服务 Job API 处理。
10. 成功报告写入共享目录，患者端和医生端均从该目录读取。

患者端不选择任务，不上传 CSV，不上传分数，也不构造报告。
