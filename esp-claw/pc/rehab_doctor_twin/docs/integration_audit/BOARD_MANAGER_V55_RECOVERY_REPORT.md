`C:\ec\esp-claw\application\edge_agent\components\gen_bmgr_codes\gen_board_device_config.c`

`gen_board_device_config.c:223: .use_dma2d = false,`

`ESP_IDF_VERSION >= ESP_IDF_VERSION_VAL(6, 0, 0)`

The locked Board Manager parser was verified under `IDF_PATH=E:\esp\.espressif\v5.5.4\esp-idf`; it returns `top_level_has_use_dma2d=False`. After regeneration, the generated DSI sub-config no longer contains the unsupported top-level field. It still contains `dpi_config.flags.use_dma2d`, which is valid for ESP-IDF v5.5.4.
